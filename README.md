# 실험실 프로젝트 관리 대시보드

차량용 윈도우 필름 같은 제품 개발 프로젝트를 여러 개 동시에 진행할 때, 프로젝트마다 **지금 어느 단계인지, 그 단계의 recipe·특성 결과가 무엇인지, 어떤 Risk와 이슈가 있었는지**를 한곳에서 보는 로컬 웹 앱입니다. 설치 없이 Python만 있으면 실행됩니다.

## 실행

```bash
python server.py
```

브라우저에서 http://localhost:8810/ 를 엽니다. Windows에서는 `start.bat`을 더블클릭해도 됩니다.

- Python 3.8 이상 (3.12에서 확인). 표준 라이브러리만 사용하고 외부 패키지는 필요 없습니다.
- 기본으로는 같은 PC의 브라우저에서만 접속됩니다.

### 같은 와이파이의 다른 사람과 같이 쓰기

```bash
python server.py --lan          # Windows는 start-lan.bat
python server.py --lan --readonly   # 보기만 허용 (저장·수정 차단)
```

서버 창에 `http://192.168.x.x:8810/` 같은 주소가 나옵니다. 같은 와이파이에 연결된 기기에서 이 주소를 열면 됩니다.

- 내 PC가 켜져 있고 서버가 실행 중일 때만 접속됩니다. PC를 끄거나 서버 창을 닫으면 접속이 끊깁니다.
- 주소(IP)는 와이파이를 바꾸거나 PC를 재시작하면 달라질 수 있습니다. 그때는 서버 창에 새로 나오는 주소를 다시 공유하세요.
- 같은 내부망(사설 IP)에서 IP 주소로 접속한 요청만 받습니다. 인터넷에서는 접속되지 않습니다.
- 일반 모드에서는 접속한 사람 누구나 입력·수정·삭제를 할 수 있고, 동시에 편집하면 서로의 입력을 덮어쓸 수 있습니다. 믿을 수 있는 사람과만 쓰거나 `--readonly`를 쓰세요.
- Windows 방화벽이 Python의 들어오는 연결을 물으면 허용해야 다른 기기에서 접속됩니다. 카페·학교처럼 클라이언트 간 통신을 막는 와이파이에서는 접속되지 않을 수 있습니다.

## 주요 기능

- **전체 프로젝트 대시보드**: 12단계 진행 매트릭스, 연속 통과, 멈춘 기간, 설계 대비 판정, 열린 Risk, 다음 할 일을 한 화면에서 확인
- **공정 흐름선**: 제품 설계 → Lab SPL 고객 승인 → [R/A → Trial production → 고객 승인] ×3 → 양산 이관 회의. 어느 차수든 Fail이면 1차 R/A부터 다시, 3연속 통과해야 이관 가능
- **시도 이력**: Fail 시도별로 어느 단계에서 왜 실패했는지 보고, 그 시도의 기록을 그대로 열람
- **제품 설계**: 제품 구조 단면 그림, 규격(평가 기준) 표, 최종 recipe·특성, 실험 이력(접고 펴기)
- **자동 판정**: 규격(`≥70`, `≤1.5`, `70~80`, `100±5`)을 한 번 정하면 Trial·고객 승인에서는 측정값만 넣어도 Pass/Fail 판정
- **설계 vs Trial 성능 비교**: 설계 기준값 대비 편차, 산포, 그래프
- **R/A Risk 관리**: Risk 등록부, 이슈·해결 이력, Trial 진행 판단과 회의 결정
- **실험 데이터(ML용)**: 모든 프로젝트의 설계 실험을 한 표로 합쳐 보기, 분포 그래프, 이상치·결측 점검과 처리(수정·유지·제외), 엑셀/CSV 내보내기
- **엑셀 내보내기**: 단계별, 프로젝트 전체, 성능 비교, Risk 이력

## 데이터

- 입력한 내용은 같은 폴더의 `data.json`에 저장됩니다. 저장소에는 가상의 예시 프로젝트 10개가 들어 있고, 이름과 값은 모두 지어낸 것입니다.
- 새로 시작하려면 `data.json`을 지우거나 `{"projects": []}`로 바꾸면 빈 상태로 시작합니다.
- 실제 실험 데이터를 입력한 뒤에는 `data.json`을 그대로 커밋하지 않도록 주의하세요. 저장소가 공개라면 `.gitignore`에 `data.json`을 추가하면 됩니다.
- 백업은 `data.json` 파일을 복사해 두면 됩니다.

## 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 로컬 서버, 데이터 저장, 엑셀·CSV 내보내기 |
| `xlsx_writer.py` | 외부 라이브러리 없이 `.xlsx`를 만드는 작성기 |
| `index.html` | 화면 전체 (HTML·CSS·JS 한 파일) |
| `data.json` | 저장 데이터 (가상의 예시 프로젝트 10개가 들어 있음) |
