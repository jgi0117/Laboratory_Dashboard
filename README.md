# 실험 데이터 허브 (조성 ↔ 성능 예측)

여러 곳에 흩어진 제품개발 프로젝트의 실험 데이터를 **한 곳에 모으고**, 모인 데이터로
**조성·공정 → 성능**을 예측하거나 **목표 성능 → 조성 후보**를 거꾸로 추천하는 로컬 웹 앱입니다.
제품개발팀이 바로 쓸 수 있게 화면을 네 개로 줄였습니다.

| 화면 | 하는 일 |
|---|---|
| **1 프로젝트** | 프로젝트 카드(상태·규격 달성·실험 수) → 규격 입력, 실험 표 바로 편집, 엑셀·CSV 가져오기, 표 붙여넣기 |
| **2 데이터** | 모든 프로젝트를 합친 통합 실험 표, 변수 사전(이름·단위 통일, 합치기), 오타·결측 점검, CSV·엑셀 내려받기 |
| **3 예측** | 조성·공정 조건 입력 → 성능 예측값·95% 구간·규격 판정, 민감도 그래프, 변수 중요도, 가장 비슷한 과거 실험 |
| **4 설계** | 목표 성능(규격) 입력 → 규격을 만족할 조성 후보 5개 추천, 후보를 실험으로 바로 등록 |

문제 정의와 설계는 [docs/01_문제정의.md](docs/01_문제정의.md), [docs/02_설계.md](docs/02_설계.md), 발표자료는 [docs/발표자료.html](docs/발표자료.html)에 있습니다.

## 실행

```bash
pip install numpy scikit-learn     # ML 기능용 (없어도 데이터 관리는 됨)
python server.py                   # → http://localhost:8810/
```

Windows는 `start.bat` 더블클릭. 같은 와이파이의 다른 기기와 같이 쓰려면 `python server.py --lan` (`start-lan.bat`), 보기만 허용하려면 `--lan --readonly`.

- Python 3.8 이상 (3.12에서 확인). 서버는 표준 라이브러리만 씁니다.
- 기본은 이 PC의 브라우저에서만 접속되고, `--lan`일 때도 사설 IP에서 온 요청만 받습니다. 데이터는 PC 밖으로 나가지 않습니다.

## 데이터

- 모든 데이터는 같은 폴더의 `data.json` 하나에 저장됩니다. 백업은 이 파일을 복사하면 됩니다.
- 저장소에는 **가상의 예시 프로젝트 10개(실험 135건)** 가 들어 있습니다. 이름과 값은 모두 지어낸 것입니다.
  빈 상태로 시작하려면 `data.json`을 지우세요.
- 이전 버전(v1, 단계별 기록 구조)의 `data.json`을 두면 처음 켤 때 자동으로 새 구조로 바꾸고 원본을 `data.v1.backup.json`으로 남깁니다.
- 학습한 모델은 `models.pkl`에 저장되어 서버를 다시 켜도 유지됩니다. 데이터가 바뀌면 화면에 "재학습 필요"가 표시됩니다.
- 실제 실험 데이터를 넣은 뒤에는 `data.json`을 공개 저장소에 올리지 마세요.

### 데이터 구조 (data.json, version 2)

```jsonc
{
  "variables":   [{"id":"v0001","name":"나노입자 함량","unit":"wt%","kind":"composition","aliases":["NP"]}],
  "projects":    [{"id":"p0001","name":"WF-C70","product":"차량용 윈도우 필름","status":"진행","stage":"1차 Trial",
                   "specs":[{"var":"v0009","spec":"≥70"}]}],
  "experiments": [{"id":"e0001","project":"p0001","date":"2025-11-03","label":"설계1-01",
                   "values":{"v0001":14,"v0009":68.7},"excluded":false}]
}
```

- `kind`: `composition`(조성) · `process`(공정) → 모델 입력, `property`(성능) → 예측 대상
- 변수는 모든 프로젝트가 공유합니다. 엑셀 열 이름이 다르면 가져오기 때 기존 변수로 맞추고, 그 이름은 별칭으로 기억됩니다.
- 규격 형식: `≥70` `≤1.5` `70~80` `100±5`

## 엑셀·CSV 가져오기

프로젝트 화면에서 파일을 고르거나 엑셀에서 복사한 표를 붙여 넣으면

1. 열 이름을 읽어 `이름 (단위)` 로 나누고,
2. 변수 사전의 이름·별칭과 맞춰 **기존 변수 / 새 변수 / 날짜 / 실험명 / 메모** 를 제안합니다 (비슷한 이름은 경고와 함께 제안).
3. 확인 후 가져오면 실험이 등록됩니다. `약 12`, `1,234` 같은 값은 숫자로 읽고, 숫자가 아닌 값은 표에 남되 모델에는 쓰지 않습니다.

UTF-8 CSV, 한글 엑셀 CSV(CP949), 탭 구분, `.xlsx`(첫 시트)를 읽습니다. `.xls`는 지원하지 않습니다.

## ML

- **정방향**: 성능 변수마다 RandomForest · GradientBoosting · Ridge를 5-fold 교차검증으로 비교해 R²가 가장 높은 것을 채택합니다.
  입력은 조성·공정 변수와 **프로젝트(제품군) one-hot** 입니다. 제품군마다 기본 성능이 다른 것(안료·구조 차이 등 변수로 적히지 않은 것)을 모델이 흡수합니다.
- **불확실성**: RandomForest는 트리별 분산, 그 밖은 교차검증 잔차로 ±95% 구간을 냅니다. 입력이 데이터 범위를 벗어나면 경고합니다.
- **역방향**: 데이터 범위 안에서 Latin Hypercube로 2,000점을 뽑아 정방향 모델로 성능을 예측하고
  `규격 위반량 + 불확실성 + 데이터와의 거리`가 작은 순으로 국소 개선 후 서로 다른 후보 5개를 돌려줍니다.
  모든 규격을 만족하는 후보가 없으면 그렇다고 알려 줍니다.
- 학습 건수가 8건 미만인 성능, 값이 늘 같은 입력은 자동으로 뺍니다. 점검에서 '제외'한 실험은 학습에 쓰지 않습니다.
- 예시 데이터 기준 5-fold CV R²: VLT 0.99 · IR 차단율 0.97 · Haze 0.97 · TSER 0.87 · UV 차단율 0.89 · 접착력 0.49 (접착력은 예시 데이터에 잡음이 큼).

## 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 로컬 서버, API 라우팅 |
| `lab/store.py` | `data.json` 읽기·쓰기, 데이터 모델 |
| `lab/dataset.py` | 통합 표, 규격 파싱·판정, 통계, 점검, 내보내기 |
| `lab/importer.py` | CSV·XLSX 읽기, 열 자동 매핑 |
| `lab/ml.py` | 학습·예측·역설계·민감도·유사 실험 |
| `lab/migrate.py` | v1 → v2 변환 |
| `xlsx_writer.py` | 외부 라이브러리 없이 `.xlsx` 만들기 |
| `index.html` | 화면 전체 (한 파일, 외부 의존 없음) |
| `tests/` | 단위·API 테스트 |
| `docs/` | 문제 정의, 설계, 발표자료 |
| `lab-note-checker/` | (별도 도구) 실험 노트 점검기. 이 앱과 독립적으로 동작 |
