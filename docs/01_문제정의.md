# 1. 문제 정의

## 1.1 배경

제품개발팀은 차량용 윈도우 필름 같은 코팅 제품을 여러 프로젝트로 동시에 개발한다.
프로젝트마다 담당자가 다르고, 실험 기록은 **개인 엑셀, 실험 노트, 메일 첨부, 공유 폴더**에 흩어져 있다.

그 결과 아래 문제가 반복된다.

| # | 문제 | 현재 모습 | 비용 |
|---|---|---|---|
| P1 | **데이터가 흩어져 있다** | 프로젝트 A의 조성-성능 결과를 프로젝트 B 담당자가 모른다 | 같은 실험을 다시 한다 |
| P2 | **열 이름·단위가 제각각** | "나노입자 함량(wt%)" vs "입자 %" vs "NP" | 합쳐서 볼 수 없다 |
| P3 | **새 목표 사양이 오면 처음부터 시작** | 고객이 "VLT 60%, IR 80%"를 요구하면 경험으로 초기 조성을 잡고 DOE를 돌린다 | 시도 횟수·기간 증가 |
| P4 | **어떤 변수가 성능을 좌우하는지 감에 의존** | "분산 시간이 Haze에 중요한 것 같다" 수준 | 설계 근거가 남지 않는다 |
| P5 | **기존 도구가 복잡하다** | 12단계 진행 매트릭스, Risk 등록부, 시도 이력 등 관리 항목이 많아 입력 부담이 크고 핵심(데이터)이 묻힌다 | 입력을 안 하게 되고 데이터가 쌓이지 않는다 |

## 1.2 목표

> **흩어진 실험 데이터를 한 곳에 모으고, 모인 데이터로 "조성 → 성능"과 "목표 성능 → 조성"을 예측해서, 다음 실험을 더 적게·더 정확하게 하도록 돕는다.**

구체적으로 세 가지만 한다.

1. **모으기 (Data Hub)** — 프로젝트와 실험을 한 화면에서 등록·조회하고, 엑셀/CSV를 가져오면 열 이름을 공통 변수로 자동 맞춘다.
2. **예측하기 (Forward)** — 조성·공정 조건을 넣으면 성능(VLT, IR 차단율, Haze 등)을 예측하고, 신뢰 구간과 "데이터 범위 밖" 경고를 함께 보여 준다.
3. **설계하기 (Inverse)** — 목표 성능(규격)을 넣으면 그 규격을 만족할 가능성이 높은 조성 후보를 추천하고, 가장 가까운 과거 실험을 같이 보여 준다.

## 1.3 사용자와 사용 장면

| 사용자 | 장면 | 필요한 것 |
|---|---|---|
| 제품개발 연구원 | 실험을 마치고 결과를 적는다 | 1분 안에 한 줄 입력, 엑셀 붙여넣기 |
| 제품개발 연구원 | 새 고객 사양을 받았다 | 목표 사양 입력 → 시작 조성 후보 3~5개 |
| 제품개발 연구원 | 조성을 조금 바꾸면 어떻게 될지 궁금하다 | 조성 입력 → 예상 성능과 민감도 |
| 팀장 | 프로젝트별 진행 현황을 본다 | 프로젝트 목록, 규격 대비 달성 여부, 최근 실험 |
| 전원 | 다른 사람의 데이터를 활용한다 | 전 프로젝트 통합 표, 검색·필터, 내려받기 |

## 1.4 범위

**한다**
- 로컬/사내 LAN에서 Python 하나로 실행 (설치 부담 최소)
- 프로젝트·실험·변수(조성/공정/성능) 통합 저장 (`data.json`)
- CSV/XLSX 가져오기 + 열 이름 자동 매핑
- 정방향 예측 모델 (성능별 자동 모델 선택, 교차검증 점수 공개)
- 역방향 설계 (규격 → 조성 후보, 데이터 범위 안에서 탐색)
- 변수 중요도·민감도 그래프
- 간단한 4개 화면: 프로젝트 / 데이터 / 예측 / 설계

**하지 않는다**
- 12단계 승인 절차·Risk 등록부 같은 관리 워크플로 (단계는 한 줄 상태값으로만 남김)
- 다중 사용자 동시 편집, 로그인, 권한
- 클라우드 배포, 외부 전송
- 모델의 자동 재학습 스케줄링 (버튼으로 학습)

## 1.5 성공 기준

| 기준 | 측정 |
|---|---|
| 데이터 통합 | 기존 10개 예시 프로젝트의 설계 실험 106건이 열 손실 없이 한 표로 보인다 |
| 예측 정확도 | 주요 성능 3개(VLT, IR 차단율, Haze)의 5-fold CV R² ≥ 0.7 (예시 데이터 기준) |
| 역설계 유효성 | 임의 규격 5개에 대해 추천 조성의 예측 성능이 규격을 만족하고, 모든 변수가 데이터 범위 안에 있다 |
| 사용성 | 실험 1건 입력 ≤ 1분, 예측/설계 결과 ≤ 3초, 화면 4개 이하 |
| 투명성 | 모든 예측에 모델 점수(R², MAE)·학습 건수·범위 밖 경고가 같이 표시된다 |

## 1.6 ML 문제 정의

- **입력 X**: 조성 변수(나노입자·바인더·광개시제 함량 등) + 공정 변수(분산 시간, 코팅 속도, 건조 온도, UV 경화량, 건조 두께)
- **출력 Y**: 성능 변수(VLT, IR 차단율, TSER, UV 차단율, Haze, 접착력)
- **정방향**: 각 Y에 대해 독립 회귀 모델. 데이터가 적으므로(수십~수백 건) 트리 앙상블(RandomForest, GradientBoosting)과 정규화 선형모델을 교차검증으로 비교해 가장 좋은 것을 고른다. 불확실성은 앙상블 분산 또는 CV 잔차로 추정한다.
- **역방향**: 학습된 정방향 모델을 "시뮬레이터"로 쓰는 최적화. 데이터 범위(각 변수의 min~max) 안에서 후보를 샘플링하고, 규격 위반량 + 데이터와의 거리(외삽 벌점) + 사용자가 고정한 변수 제약을 점수로 매겨 상위 후보를 돌려준다. 결과에는 예측 성능, 불확실성, 가장 가까운 실제 실험을 붙인다.
- **한계 공지**: 모델은 데이터 범위 안에서만 유효하다. 새 재료·새 층 구조는 데이터가 쌓이기 전까지 예측하지 않고 "유사 실험 조회"로 대체한다.
