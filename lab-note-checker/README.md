# 실험 노트 점검기

실험 데이터(엑셀·CSV 표)를 **누적해서 저장**해 두고, **빠지거나 틀린 기록을 찾아 주고, 결과를 여러 방식으로 그려 보여 주는** 로컬 웹 앱입니다.
목적은 보고서를 쓰는 것이 아니라 **기록하는 순간에 잘못 적거나 빼먹는 일을 줄이는 것**입니다.

## 웹 데모 (GitHub Pages)

서버 없이 브라우저만으로도 열립니다. 서버가 없으면 자동으로 **데모 모드**로 전환되어, 가상 예시 표 가져오기, CSV 가져오기, 점검, 통계, 행 직접 입력이 모두 브라우저 안에서 동작하고 입력한 내용은 **그 브라우저(localStorage)에만** 저장됩니다. 서버에 올라가는 것은 없습니다. 데모에서 안 되는 것은 xlsx 가져오기이고(내 PC에서 `python server.py`로 실행하면 됩니다), 틀 엑셀은 저장소에 올려 둔 `lab-note-template.xlsx`를 내려받습니다(틀을 바꾸면 서버의 '틀만 있는 엑셀 받기'로 다시 만들어 교체하세요). 시험용 가상 데이터는 `sample-data.csv`입니다.

공개 주소는 저장소의 Settings → Pages에서 Branch를 `main` / `(root)`로 두면 `https://<아이디>.github.io/<저장소>/lab-note-checker/`로 열립니다.

## 실행

```bash
python server.py
```

http://localhost:8840/ 을 엽니다. Windows에서는 `start.bat` 더블클릭도 됩니다.

- Python 3.8 이상, 외부 패키지 없음.
- 가져오기·점검·통계·저장은 모두 AI 없이 이 PC의 코드로만 동작합니다. 화면에서 AI 기능(메모 입력, AI 의미 점검)은 일단 뺐습니다. 서버 쪽 코드(`server.py`의 Claude Code 호출, `prompts.py`)는 나중에 다시 붙일 수 있게 남겨 두었지만 화면에서는 호출되지 않습니다.
- 내 구독 계정을 쓰므로 **본인 PC에서 혼자 쓰는 용도**입니다.

## 실험 틀 (입력·출력 항목, 고정)

한 실험 시리즈에서는 입력(조건)과 출력(결과) 항목이 매번 같으므로 **틀을 코드에 고정**했습니다(화면에서 편집하지 않음). 유리기판 TGV 구리 충진 전해도금 실험 기준으로 입력 13개(기판 크기·두께, TGV 직경, 시드층 두께, Cu 농도, 억제제·가속제·평탄제 농도, 욕 온도, 전류 파형, 전류밀도, 도금 시간, 교반), 출력 8개(충진율, 기공률(X-ray), 보이드, 딤플 깊이, 표면 도금 두께, 두께 편차, 접착력, 기판 휨), 기타 1개(비고)입니다. 일반적인 공정 변수를 가정한 가상 예시입니다. 항목을 바꾸려면 `index.html`의 `EXSCHEMA` 목록을 고치세요.

- **가져올 때 대조**: 파일의 열을 틀과 비교해 보여 줍니다. 틀에 없는 새 열, 파일에 없는 틀 항목(출력 열이 빠지면 모든 행이 결측으로 점검됨), 단위 차이를 알려 주고, 이름이 비슷한 열(예: `두께` ↔ `표면 도금 두께`)은 합칠지 묻습니다.
- **열 구분은 틀이 정함**: 틀에 없는 열은 표에 '틀 밖'으로 표시되고, 구분은 이름으로 추측한 값입니다.
- **직접 입력**: 틀의 항목이 처음부터 열로 있어서, 데이터가 없어도 행을 추가해 바로 입력할 수 있습니다.

## 상단 도식

화면 상단에는 TGV 구리 충진 도금 실험의 맥락을 보여 주는 도식이 있습니다: ① 공정 흐름(유리 소재 → TGV 가공 → 세척·전처리 → 시드층 → **구리 충전 도금** → 연마 → X-ray 기공 검사), ② 국부 이온 농도 제어 도금 장비 **개념도**, ③ TGV 충진 단면(기공·딤플·완전 충진). 공개된 보도에서 확인되는 공정 순서와 관리 항목(기공률, 도금 두께, TGV 함몰 깊이, 변형량)에 맞춰 직접 그린 것이며, 장비 내부 구조는 공개되어 있지 않아 일반적인 원리만 표현한 개념도입니다. 실제 사진을 쓰고 싶으면 이 폴더에 `hero.jpg`(또는 `.png`, `.webp`, 8MB 이하)를 넣으면 도식 뒤 배경으로 깔립니다. 사진은 사용 허가가 있는 것만 쓰세요.

## 데이터 흐름

| 입력 방법 | 설명 |
|---|---|
| 엑셀(.xlsx)·CSV 파일 | 파일 선택 또는 끌어다 놓기. 첫 시트의 첫 행이 머리글. 머리글의 `(μm)` 같은 괄호는 단위로 읽고, 실험 이름·날짜 열은 자동으로 찾습니다. CSV는 UTF-8과 한글 엑셀 CSV(CP949) 모두 읽습니다 |
| 표 붙여넣기 | 엑셀에서 복사한 표를 그대로 붙여 넣기 |
| 직접 입력 | '3 표 확인'에서 행을 추가해 바로 입력. **"직전 행의 조건 복사해서 추가"** 로 조건만 이어받고 결과는 비워 둘 수 있습니다. 빈 결과 칸은 곧바로 '결측'으로 표시됩니다 |

가져올 때마다 **묶음**으로 기록되어, 잘못 가져온 파일은 묶음째 삭제할 수 있습니다. 같은 이름의 파일을 다시 가져오려 하면 경고하고, 모든 값이 같은 행은 점검에서 '중복'으로 잡습니다. 열 이름이 같으면 기존 열에 이어 붙고, 다르면 새 열이 생깁니다.

## 저장

- 칸을 고치거나 행을 추가·삭제할 때마다 **0.4초 안에 자동 저장**됩니다. 화면 오른쪽 위에 저장 시각이 보입니다.
- 저장 위치는 이 폴더의 `data.json` 하나뿐이고, 서버를 켤 때마다 직전 상태를 `data.backup.json`으로 복사해 둡니다. 두 파일은 `.gitignore`에 들어 있어 git에 올라가지 않습니다. 다른 PC로 옮기려면 `data.json`을 복사하세요.
- 저장된 파일을 읽지 못하면 빈 데이터로 덮어쓰지 않도록 자동 저장을 끕니다.
- 화면 UI 상태(탭, 입력 중이던 메모)는 브라우저 탭 안(sessionStorage)에만 보관합니다.

## 화면

| 단계 | 하는 일 |
|---|---|
| 1 입력 | 고정 틀 안내, **틀만 있는 엑셀(.xlsx) 내려받기**, 엑셀·CSV 파일 가져오기, 가상 예시 표 가져오기, 가져온 묶음 목록 |
| 2 표 확인 | 누적 표(15행씩). 칸 직접 수정, 행 추가·삭제 |
| 3 점검 | 결측, 숫자 아님, 이상치·자릿수 의심, 단위 불일치, 불확실한 표기, 중복 행, (메모 입력 시) 메모와 표의 값 충돌. 항목마다 **고치기 / 확인했고 그대로 둠 / 통계에서 제외**, 단위가 다르면 환산해서 고치기 |
| 4 통계 | 범위(전체 누적 또는 묶음 하나)를 고르고 목적별 하위 탭으로 봅니다. **요약표**(항목별 평균·범위·빈칸), **기록 현황**(항목별 빈칸 수와 행×항목 지도), **입력 → 출력**(산점도·상관계수, 입력별 출력 비교, 상관 히트맵), **실험 순서별 추이**, **분포·이상치**(히스토그램·상자 그림). 누적 표 CSV 저장 |

## 점검 방식

- **코드**: 파일 읽기, 단위·숫자·불확실 표기 분리, 결측·중복·이상치(출력 열에서 IQR×3 + 중앙값 대비 30% 이상, 자릿수는 8배 이상 차이) 점검, 통계, 그래프, 저장. 모두 코드가 계산하며 AI를 쓰지 않습니다.
- 입력 열(사람이 일부러 바꾼 값)은 이상치로 보지 않습니다. 결과 열의 이상치도 조건 때문에 실제로 달라진 값일 수 있어서 "확인하세요"로만 안내합니다. 틀에 없는 열의 구분은 이름으로 추측한 값이므로 '틀'에서 확인하세요.

## 지키는 원칙

- '문제 없음', '검증 완료' 같은 판정을 만들지 않습니다. 걸린 항목이 없어도 원자료 대조는 직접 해야 합니다.
- 요청 내용은 서버 로그에 남기지 않고, 이 PC의 브라우저에서 온 요청만 받습니다.
- 입력한 데이터는 이 PC 밖으로 나가지 않습니다(웹 데모에서는 보는 사람의 브라우저에만 저장).

## 알아둘 점

- 가상 예시(예시 표·예시 메모)는 실제 데이터가 아니며 소수점 오기입, 단위 혼용, 불확실 표기, 빠진 값, 숫자가 아닌 값을 일부러 넣었습니다.
- 옛 `.xls` 형식은 읽지 못합니다(.xlsx나 CSV로 저장). xlsx는 첫 시트만 읽고, 병합 셀·수식 결과가 아닌 서식은 지원하지 않습니다. 한 번에 2000행, 10MB까지.
- 날짜 열은 엑셀 날짜 번호를 날짜로 바꿔 읽습니다. 날짜 열을 찾지 못하면 일반 열로 취급합니다.
- 이상치 판정은 결과 열의 값이 5개 이상일 때만 적용됩니다.
- 하지 않는 것: 여러 시트 선택, 사진·장비 원본 파일 첨부, 사용자 여럿의 동시 편집, 결과 해석·결론 작성.

## 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 로컬 서버, xlsx·CSV 읽기, 자동 저장(`data.json`), Claude Code 호출, 메모 표 구조 검증 |
| `prompts.py` | (현재 화면에서 쓰지 않음) 나중에 AI 기능을 다시 붙일 때 쓸 프롬프트 |
| `index.html` | 화면, 점검 로직, 그래프 |
